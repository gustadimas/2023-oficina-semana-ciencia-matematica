# Oficina de matemática

Atividade da faculdade de out/2023. Publiquei anos depois (nov/2026) e não atualizei nada.

Projeto que preparei pra uma oficina de matemática na Semana de Ciência, em 09/10/2023. São exemplos de atividades em que você arrasta peças até o lugar certo. No exemplo 3 a peça também precisa estar no ângulo certo, e quando todas encaixam o `VerificadorVitoria.cs` avisa que você ganhou.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2021.3.18f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
